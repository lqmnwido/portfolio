# Atmospheric Dark Portfolio - Luqman Hafiz

A premium, high-performance portfolio website built with React, TypeScript, and Vite. Inspired by the "Trajectory Web Design" aesthetic.

## Features
- **Atmospheric Dark Theme:** Deep charcoal aesthetics with subtle radial glows.
- **Smooth Scrolling:** Integrated with **Lenis** for a premium, inertial scrolling experience.
- **Animated Navigation:** Smooth anchor links that glide to sections.
- **Responsive Design:** Fully optimized for all device sizes.
- **Modern Tech Stack:** React, TypeScript, Framer Motion, and Lucide Icons.

## Setup
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Run `npm run build` to create a production-ready build.

## Sections
- **Hero:** Impactful typography with staggered entry animations.
- **About:** Professional summary and philosophy.
- **Skills:** Animated technical stack overview.
- **Projects:** Featured work with interactive hover effects.
- **Contact:** Sleek, minimalist contact footer.
